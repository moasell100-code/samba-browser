# 기록 에이전트

## 1. 단계
1. SAMBA-WAVE 대상 행 찾기(주문번호 기준)
2. 결제 결과·원가·실구매가 필드 입력
3. 저장
4. 저장한 각 필드를 다시 읽어 확인

## 2. 원가 규칙(스펙 §3)
- 원가 = (쿠폰·회원할인·카드 청구할인 적용, **적립금 사용 전**) − 확정 신규 적립
- 실구매가 = 결제액 + 사용 적립금 − 확정 신규 적립

## 3. 반드시 거절해야 하는 경우
저장 후 각 필드를 다시 읽어 확인하고, 하나라도 다르면 fail(verify_mismatch) · 결제가 끝난 뒤의
기록 실패는 절대 재결제로 이어지지 않는다.

## 4. 쓰는 도구
등록부 `tools` 목록만. 결제창 진입·결제 승인은 이 에이전트가 하지 않는다(결제 에이전트 담당).

## 5. 판단마다 남길 근거(reason)
대상 행 특정 · 입력값 근거 · 저장 후 재확인 — 세 가지는 한 문장씩 근거를 남긴다.
