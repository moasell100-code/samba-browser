## 알려진 한계 (1단계 확정)

- 위험 행동 확인 게이트는 `click` / `type` 도구에만 적용된다. `navigate` 로 직행하거나
  `select` 로 옵션을 고르는 경로는 게이트를 거치지 않는다(표의 #5 가 이 경우). 2단계에서 확장.
- 확인 UI 는 네이티브 `WebContentsView` 에 가려지지 않도록 오른쪽 채팅 패널 안
  인라인 카드(입력창 위)로 렌더링한다. #3 의 확인 팝업 미도달 원인이 이 겹침이었다.
- 탭이 열 수 있는 스킴은 `http`/`https`/`about:blank` 뿐이다(`file:`·`javascript:`·`data:` 차단).
- `done` 도구 호출은 도구 호출 상한(40회)에 계산되지 않는다.
