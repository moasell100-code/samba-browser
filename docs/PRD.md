# 삼바브라우저 PRD (Product Requirements Document)

작성일: 2026-09-18 · 버전 1.2 · 상태: 검토용 초안 · 참고: [Aside 실물 검토](reference/aside-검토.md)
상세 근거: [01 문제정의](prd/01-문제정의.md) · [02 업무·데이터](prd/02-업무-데이터분석.md) · [03 UX·IA](prd/03-UX-IA설계.md) · [04 구조·명세](prd/04-시스템구조-기능명세.md)

## 1. 한 줄 정의

**사람이 하는 웹 작업(로그인·본인인증·결제 포함)을 AI가 대신 끝내주는 Chromium 기반 데스크톱 브라우저.** 안드로이드 폰을 브라우저 안에 연결해 문자·ARS 인증까지 스스로 처리한다.

## 2. 문제

- 웹에서 뭔가를 사거나 예약하려면 로그인 → 본인인증(문자/전화) → 결제 정보 입력을 매번 사람이 해야 한다.
- 인증 문자는 폰에 오고, 폰이 여러 대(3대, 한·중·일 유심)면 어느 폰인지 찾아 옮겨 적어야 한다.
- 기존 AI 브라우저 도구는 인증·결제 앞에서 멈춘다. 크롬·웨일의 자동저장은 로그인 아이디/비밀번호까지만이다.

## 3. 목표와 KPI

- 목표: 사용자가 채팅으로 지시하면 인증·결제까지 사람 손 없이 완료.
- **KPI: 무인 처리율 80% 이상** (사람 개입 0회로 끝난 작업 비율).

## 4. 사용자 · 제품 형태

- **제품 형태: AI 브라우저 SaaS** (다중 사용자 구독 서비스). 회원가입 → 앱 다운로드 → 로그인 → 요금제.
- **첫 사용자 = 개발 의뢰자 본인**: 온라인 구매·예약 반복 작업(부록 A), Windows 11, 안드로이드 폰 3대. 이 사용자의 시나리오로 MVP 검증 후 일반 공개.
- **언어: 한국어 · 영어** (UI 전체 i18n, 설정에서 전환, AI 응답도 사용자 언어).

## 5. 핵심 기능

| # | 기능 | 설명 |
|---|---|---|
| F1 | AI 채팅 브라우저 | 오른쪽 채팅 패널에 지시 → AI가 페이지 구조를 읽고 클릭·입력·이동 실행. 진행 로그 표시, 중단 버튼 |
| F2 | 탭·프로필 분리 | 다중 탭, 탭마다 브라우저 프로필(쿠키 분리). 계정 = 프로필 |
| F3 | PC↔모바일 전환 | 주소창 옆 토글. 모바일 UA·뷰포트·터치 에뮬레이션. 나란히 보기 옵션 |
| F4 | Vault(금고) | 계정별 로그인 비밀번호·결제비밀번호·카드·여권·신분증·생년월일 저장. **AI는 값을 못 보고 이름으로만 지시**, 앱이 직접 입력 |
| F5 | 자동 저장 제안 + 결제 흐름 학습 | 사람이 로그인·결제하면 감지해 "저장할까요?" 제안. 결제 단계·입력칸 역할을 분석해 사이트별 절차로 저장 |
| F6 | 폰 연동 | adb+scrcpy로 폰 3대 화면을 패널에 표시, 터치·키 전달. 인증 때 자동 펼침 |
| F7 | 문자 인증 자동 입력 | adb로 문자함 1초 폴링 → 인증번호 추출 → 입력. 실패 시 폰 화면을 AI가 읽음 |
| F8 | ARS 전화 인증 | 통화 감지 → 소리를 PC로(scrcpy voice-call → 스피커폰+마이크 → 블루투스 순) → AI가 듣고 폰 키패드 터치 |
| F9 | 기록·재생 | AI 수행 절차 또는 **사람 작업을 이벤트 흐름으로 녹화**(장면 캡처 아님)해 레시피로 저장, 다음부터 AI 없이 재생. 실패 단계만 AI 개입 → 절차 갱신 |
| F16 | 대화 메모리 | 채팅에서 나온 지시·선호를 기억해 다음 작업에 자동 반영. 대화 끝에 자동화 저장 제안. 메모리 화면에서 관리 |
| F17 | 계정·요금제 | 회원가입/로그인(이메일·구글), Free/Pro 요금제, 월 크레딧·사용량 화면, 결제(토스페이먼츠·Stripe), AI는 본인 구독 가져오기 또는 서비스 크레딧 |
| F18 | 다국어 | 한국어·영어 UI, 번역 파일 분리, 설정 전환 |
| F10 | 작업·자동화 | 작업 목록(실행중/대기/완료/실패/확인필요), 레시피(지시문+사이트+계정+규칙) 저장·반복 실행 |
| F11 | 안전장치 | 위험 단어·결제 상한 확인 팝업, 비밀값 직접 입력 금지, 도구 호출 상한, 봇 차단 감지 시 중지 |
| F12 | 로그·KPI | 작업 단계 로그, 인증 이벤트, 무인 처리율 |
| F13 | 가져오기 | 크롬·웨일·엣지에서 북마크·히스토리·비밀번호 가져오기, 1Password/Bitwarden/CSV 비밀번호 가져오기, 내보내기(CSV/JSON) |
| F14 | 작업별 모델 지정 | Fast(재생 복구)/Standard/Deep(계획)/Visual(폰 화면·스크린샷) 용도별 모델 선택. 제공자 교체 가능 |
| F15 | 에이전트 편의 | 완료 알림·사운드, 후속 지시 큐, 에이전트 탭 자동 정리, 북마크 폴더 사이드바 |

## 6. 화면 구조

왼쪽 세로 메뉴: **브라우저 · 작업 · 자동화 · 계정(Vault) · 폰 · 로그 · 설정**.
브라우저 화면: 탭줄 → 주소창(PC/모바일, 프로필) → 진행 띠 → 웹뷰 / 오른쪽 AI 채팅 + 폰 패널.
상태별 규칙: 실행 중 진행 띠, 인증 대기 폰 패널 펼침, 사람 확인 팝업(30분), 실패 빨간 배지.

## 7. 기술 구조 (요약)

- Electron(Chromium) + TypeScript + React 19 + Tailwind + shadcn/ui + Zustand
- AI: 제공자 어댑터 — Claude 구독(Agent SDK) / ChatGPT 구독(Codex CLI) / API 키 / 로컬 AI. 도구는 MCP 공용
- 폰: adb 1.0.41 + scrcpy 4.1 (PATH 미등록, 전체 경로)
- 저장: 로컬 SQLite + **Supabase 동기화**(같은 계정으로 여러 PC에서 채팅·설정·계정·Vault·레시피·로그 공유)
- Vault: 마스터 비밀번호 E2E 암호화(Supabase도 내용 못 봄) + 로컬 DPAPI
- 상세: [기술스택.md](기술스택.md)
- 모듈: Browser · Agent · Recorder · Phone · Vault · JobRunner · Store · Settings

## 8. 수동 · 자동 경계

| AI/앱이 함 | 사람이 함 |
|---|---|
| 페이지 탐색·클릭·입력, 인증번호 입력, ARS 응답, 결제 버튼, Vault 값 자동 입력 | Vault에 정보 최초 등록(또는 자동 저장 제안 승인), 새 계정 가입, 확인 팝업 응답, 실패 재지시 |

## 9. 안정성 규칙 (기본값, 설정 변경 가능)

동시 실행 사이트당 1·전체 3 · 일시 오류 재시도 2회 · 결제 상한 50만원 · 위험 단어 확인 · 봇차단/로그인실패 시 30분 중지 · 인증 3분 타임아웃 · 절전 방지 · Vault 자동 잠금 · SQLite 일 1회 백업.

## 10. 범위 밖 (이번 버전)

- 아이폰 (원격 터치 불가)
- 인터넷 전화번호(Twilio 등) — 사이트 거부 위험
- 팀·조직 공유 기능(2차 버전). 개인 계정 다중 PC 동기화는 범위 안
- 폰 푸시 알림
- 삼바 주문 이행 자동화 세부 (부록 A, 브라우저 완성 후 진행)

## 11. 위험과 대응

| 위험 | 대응 |
|---|---|
| Claude 구독을 외부 앱에서 못 쓰게 될 수 있음 | Agent 모듈 한 곳만 API 키 방식으로 교체 |
| 구독 한도 초과 | 기록·재생으로 호출 90% 절감 |
| 윈도우가 블루투스 헤드셋 역할 미지원 | scrcpy voice-call·스피커폰 우선 |
| 삼성 폰 문자 DB 접근 제한 | 폰 화면 AI 읽기로 자동 전환 |
| 봇 차단·계정 잠금 | 프로필 분리, 동시 1, 중지 규칙 |

## 12. 단계별 구축 순서 (MVP 사이클)

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| 1 | 브라우저 뼈대: 탭·프로필·PC/모바일·AI 채팅(자유 지시) | "구글에서 X 검색해" AI가 완료 |
| 2 | Vault + 계정 화면 + 자동 저장 제안 | 사이트 로그인·결제 정보 저장 후 AI가 값 안 보고 입력 |
| 3 | 폰 연동 + 문자 인증 자동 입력 | 인증 문자 → 자동 입력 성공 |
| 4 | 기록·재생 + 작업·자동화 화면 | 같은 작업 2회째 AI 호출 없이 완료 |
| 5 | ARS 전화 인증 | 통화 안내 듣고 번호 눌러 인증 완료 |

각 단계: 구축 → 수동 검수 15회 이상 → 안정화 → 다음 단계.

## 13. 용어

- **스냅샷**: 페이지 텍스트 + 버튼/입력칸 번호 목록. AI가 보는 것.
- **프로필**: 쿠키·로그인 상태가 분리된 브라우저 공간.
- **레시피**: 반복 작업 정의(지시문·사이트·계정·규칙).
- **기록·재생**: AI 절차를 저장해 AI 없이 반복.
- **Vault**: 비밀정보 금고. AI 접근 불가.
