# 3차 UX · IA 설계 — 삼바브라우저

작성일: 2026-09-18 · 상태: 확정

## 제품 정의 (재정렬)

**범용 AI 브라우저.** Chromium(Electron) 기반. 사람이 하는 웹 작업(로그인·인증·결제 포함)을 AI가 대신 수행. 삼바 주문 이행은 첫 번째 타깃 자동화 작업일 뿐, 제품 자체는 삼바에 종속되지 않음.

## 정보 구조 (메뉴)

왼쪽 세로 메뉴바(웨일 방식). 각 메뉴 목표 하나.

| 메뉴 | 핵심 목표 | 주요 요소 |
|---|---|---|
| **브라우저** | 웹 작업 실행 | 탭, 주소창, PC↔모바일 전환 버튼, AI 채팅 패널(오른쪽), 폰 패널(펼침) |
| **작업** | 작업 상태 한눈에 | 목록(실행중/대기/완료/실패/확인필요 필터), 재처리, 중단 |
| **자동화** | 반복 작업 저장·실행 | 레시피 목록, 실행/일시정지, 스케줄(추후) |
| **계정** | 사이트별 계정 관리 | 사이트 → 계정 목록, 프로필 분리, 중지 해제 |
| **폰** | 폰 연결 관리 | 폰 카드(별칭·국가·연결·마지막 시각), 미리보기, 재연결 |
| **로그** | 무슨 일이 있었나 | 작업별 단계 로그, 인증 이벤트, KPI(무인 처리율) |
| **설정** | 동작 규칙 | 모델, 금액 상한, 위험 단어, 중지 시간, adb/scrcpy 경로 |

## 브라우저 화면 배치

```
┌──┬────────────────────────────────────────┬──────────────┐
│메│ [탭1: 타오바오 ⓐ마놀] [탭2: 타오바오 ⓑ서브] [+]   │ AI 채팅       │
│뉴│ [←][→][⟳] 주소창            [PC|📱] [프로필▾] │              │
│바│ ▓▓▓▓ 작업 진행 띠: 3/7 가격 비교 중  [중단] │ 대화·진행 로그 │
│  ├────────────────────────────────────────┤              │
│  │                                        ├──────────────┤
│  │            웹페이지                     │ 📱 폰 패널    │
│  │                                        │ (접힘/펼침)   │
│  │                                        ├──────────────┤
│  │                                        │ 입력칸 [전송] │
└──┴────────────────────────────────────────┴──────────────┘
```

- **탭**: 다중 탭. AI가 계정 비교 시 계정별 탭 자동 생성, 탭에 계정 별칭 배지.
- **PC↔모바일 전환**: 주소창 옆 토글. 모바일 = 갤럭시 UA + 412×915 + 터치 에뮬레이션. 웨일 "모바일 창"처럼 옆에 나란히 띄우기 옵션.
- **프로필**: 탭마다 브라우저 프로필(쿠키 분리) 지정. 계정 선택 = 프로필 선택.
- **오른쪽 패널**: 위 AI 채팅, 아래 폰 패널. 드래그로 폭 조절, 접기 가능.
- **폰 패널**: 평소 접힘. 인증 대기 시 자동 펼침, 폰 3대 중 문자/전화 온 폰 강조. 수동 펼침도 가능.

## 상태별 화면 규칙

| 상태 | 화면 |
|---|---|
| 작업 실행 중 | 탭 상단 진행 띠(단계 n/N, 현재 행동, [중단]). 채팅 패널에 한 줄 로그 누적 |
| 인증 대기 | 폰 패널 자동 펼침, 해당 폰 테두리 강조, 진행 띠 "인증 대기 (남은 시간)" |
| 사람 확인 필요 | 화면 중앙 팝업(무엇을·왜·[승인][거부]). 30분 무응답 → 실패 처리 |
| 완료 | 진행 띠 초록 3초 후 사라짐, 작업 목록에 완료 |
| 실패 | 작업 목록 빨간 배지 + 메모. 클릭 → 상세 로그 |
| 폰 연결 끊김 | 폰 카드 회색 + [재연결] 버튼, 인증 필요 작업은 "인증대기"에서 멈춤 |
| AI 인증 실패(로그인 없음/한도) | 채팅 패널 상단 노란 띠 + 해결 방법 링크 |

## 첫 번째 타깃 자동화: 삼바 주문 이행 (레시피 예시)

- 지시문: "삼바 주문페이지에서 미처리 주문을 읽어 최저가 소싱처·계정·결제수단으로 결제하고 결과를 주문페이지에 입력"
- 대상 사이트: 삼바 주문페이지 + 소싱처 목록(2차 문서 참조)
- 예외 규칙: 2차 문서 표 그대로
