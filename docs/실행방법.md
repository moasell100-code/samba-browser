# 삼바브라우저 실행 방법 (초보자용)

## 1. 준비물 (한 번만)
1. Node.js 20 이상 — 이미 설치됨 (터미널에서 `node -v` 로 확인)
2. pnpm — 터미널에서 `corepack enable` 한 번 실행
3. Claude Code 로그인 — 터미널에서 `claude` 실행 후 로그인돼 있으면 끝. 안 돼 있으면 `claude login`

## 2. 처음 실행
1. 터미널 열기 (Windows 키 → "터미널")
2. 프로젝트 폴더로 이동: `cd <프로젝트 폴더>` (예: `cd C:\Users\canno\workspace\samba_browser`)
3. `pnpm install` (부품 내려받기, 1~3분)
4. `pnpm dev` → 브라우저 창이 뜸

## 3. 매일 실행
터미널에서 프로젝트 폴더로 이동(`cd <프로젝트 폴더>`) → `pnpm dev`

## 4. 써보기
- 오른쪽 채팅에 "구글 열어서 삼바웨이브 검색해" 입력 → AI가 진행 로그를 보여주며 수행
- 진행 띠의 [중단]으로 멈춤
- 주소창 옆 PC / 모바일 로 화면 전환
- 위험한 행동(결제·구매·삭제 등)은 채팅창 아래에 노란 확인 카드가 뜸 → [승인] / [거부]
  - 확인 카드는 **클릭·입력** 행동에만 나옴. 주소 이동(navigate)은 확인 없이 진행됨
- 왼쪽 **키마스터**: 마스터 비밀번호 설정 후 CSV(비밀번호)·HTML(북마크) 가져오기. 로그인창의 아이디 칸을 누르면 저장된 계정 목록이 바로 뜨고, 고르면 자동 입력
- AI 에게 "네이버 로그인해" 라고 하면 키마스터의 계정으로 로그인. 이미지 캡차는 AI 가 화면을 보고(`screenshot`) 또는 글자를 읽어서(`ocr`) 처리
- 로컬 OCR 은 처음 쓸 때 한국어 인식 모델(약 18MB)을 `%APPDATA%\SAMBA Browser\models\ocr` 에 한 번 내려받음. 인터넷 필요

## 4-1. 계정 만들고 두 PC 연결하기 (2b)
1. **Supabase 준비**(한 번만): `docs/supabase-설정.md` 대로 프로젝트를 만들고 `supabase/schema.sql` 을 SQL Editor 에서 실행한 뒤, 프로젝트 폴더에 `.env` 를 만든다(`SAMBA_SUPABASE_URL`, `SAMBA_SUPABASE_ANON_KEY`). `.env` 는 절대 커밋하지 않는다
2. 앱 → 설정 → **계정** → 회원가입(이메일·비밀번호) → 바로 로그인됨. Supabase 의 "Confirm email" 이 켜져 있으면 메일 확인 후 로그인
3. 로그인되면 기존 계정·북마크·설정이 자동으로 서버에 올라간다(수천 건이면 1~2분). 설정 → 계정 → 동기화 상태의 "대기 변경" 이 0 이면 완료
4. **두 번째 PC**: 같은 방법으로 앱을 설치하고 같은 계정으로 로그인 → 키마스터 탭에서 **첫 PC 와 같은 마스터 비밀번호** 입력 → 계정·북마크·키마스터·설정·채팅이 내려온다(60초 주기, "지금 동기화" 로 즉시)
5. 설정 → 계정 → 기기 목록에서 다른 PC 를 **원격 로그아웃** 할 수 있다(그 PC 는 다음 주기에 로그아웃·키마스터 잠금)
   - ⚠️ **채팅 내용은 암호화 없이 평문으로 서버에 올라간다**(키마스터의 비밀값만 기기에서 암호화된다). 대화에 비밀번호·카드번호 같은 값을 적지 않는다
6. 복구 키: 설정 → 보안 → **복구 키 재발급** → 24자 키를 안전한 곳에 보관. 마스터 비밀번호와 복구 키를 둘 다 잃으면 키마스터를 열 수 없다

## 4-2. 폰 연동 (3단계, Pro)
1. 폰에서 **개발자 옵션 → USB 디버깅** 켜고 USB 로 PC 에 연결(첫 연결 시 폰에 뜨는 "USB 디버깅 허용" 승인)
2. 앱 → **폰** 화면 → 도구 카드에서 **adb·scrcpy 설치**(원클릭, 앱 데이터 폴더에 내려받음). 이미 깔려 있으면 경로만 확인
3. 기기 목록에 폰이 뜨면 **연결** → 화면 스트림·문자 권한 확인. 사이트별로 인증 폰을 지정할 수 있다
4. AI 작업 중 문자 인증번호는 자동으로 읽어 채우고, 결제 승인은 앱 안 폰 화면에서 **사용자가 직접** 비밀번호를 누른다(AI 는 그 화면을 보지 않는다)

## 4-3. 새 기능 빠르게 써보기 (3단계)
- **제스처**: 페이지에서 오른쪽 버튼을 누른 채 ← / → / ↑ / ↓ 로 끌기. 설정 → 동작 → 마우스 제스처에서 조합 변경
- **번역**: 주소창 오른쪽 번역 아이콘 → 대상 언어 → "이 페이지 번역". 이미지는 우클릭 → 이미지 번역
- **캡처**: 주소창 카메라 아이콘 또는 `Alt+1~6`. 저장 폴더는 설정 → 일반 → 캡처
- **확장**: 확장 페이지 → "확장 설치" → 웹스토어에서 원하는 확장의 **Chrome에 추가** 클릭

## 5. 문제가 생기면
| 증상 | 해결 |
|---|---|
| 채팅에 노란 띠 "AI 연결이 안 됐어요" | 터미널에서 `claude login` |
| "사용 한도" 띠 | 몇 시간 뒤 재시도 또는 설정에서 API 키 |
| AI가 오래 응답이 없음 | 구독 사용 한도일 수 있음. 진행 띠의 [중단] 누르고 잠시 후 재시도 |
| 창은 뜨는데 웹페이지가 안 보임 | 창 크기 한 번 바꿔보기, 그래도 안 되면 `pnpm dev` 재실행 |
| `pnpm` 없다고 나옴 | `corepack enable` 후 터미널 다시 열기 |
| 코드를 고쳤는데 앱에 반영이 안 됨 | 화면(renderer)은 저절로 반영되지만 `src/main`·`src/preload` 변경은 앱을 닫고 `pnpm dev` 다시 실행 |
| 로그인창에 계정 목록이 안 뜸 | 키마스터가 잠겨 있으면 "잠금 해제 필요"만 뜸. 왼쪽 키마스터에서 해제 |
| OCR 이 "모델 없음" | 인터넷 연결 확인 후 다시 시도(첫 1회 다운로드) |
| 계정 화면에 "Supabase 설정이 필요해요" | `.env` 가 없거나 비어 있음. 4-1 의 1번 |
| 로그인 시 "이메일 또는 비밀번호가 맞지 않아요" | 가입 때 쓴 비밀번호 확인. Supabase 대시보드 Authentication → Users 에서 상태(확인 대기 여부) 확인 |
| 두 번째 PC 에 데이터가 안 내려옴 | 첫 PC 의 "대기 변경" 이 0 인지, 두 번째 PC 에서 "지금 동기화" 눌렀는지 확인 |

## 6. 코드 검사

- `pnpm lint` — 코드 규칙 검사
